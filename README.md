# 🎮 Neon Ball Game

A futuristic neon arcade ball-catching game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
[Play Neon Ball Game](https://rihan22786.github.io/neon-ball-game/)

## ✨ Features
- Multiple game modes
- Neon-themed visual design
- Power-ups and special abilities
- Sound effects and music
- Pause and resume functionality
- Score and timer system

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
